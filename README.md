# Sirius Studio

Site et espace de travail de Sirius Studio : vitrine, demandes clients et administration.

## Stack

- React 19, TypeScript, Vite, Tailwind CSS
- API, PostgreSQL, authentification
- Docker et Netlify

## Démarrage

```bash
cp .env.example .env
npm install
npm run dev
```

Les variables de production (base, JWT, e-mail) se renseignent au déploiement. Les fichiers d'exemple ne contiennent pas de clés réelles.

Voir `DEPLOIEMENT.md` pour la mise en ligne.
