# Sirius Studio — Site Vitrine

Site vitrine premium pour **Sirius Studio**, spécialisé dans la création de sites web, applications mobiles et logiciels sur mesure.

## Lancer le projet

```bash
npm install
npm run dev
```

Le site sera accessible sur [http://localhost:5173](http://localhost:5173).

## Build production

```bash
npm run build
npm run preview
```

## Stack

- **React 19** + **TypeScript**
- **Vite** — build ultra-rapide
- **Tailwind CSS v4** — styling utility-first
- **Framer Motion** — animations fluides

## Sections

| Section | Description |
|---------|-------------|
| **Hero** | Message principal + CTA « Ma maquette gratuite » |
| **Parcours** | 3 situations client (site existant, idée, incertitude) |
| **Avant/Après** | Slider interactif de transformations |
| **Processus** | Animation de construction de maquette en 4 étapes |
| **Services** | Sites web, apps mobiles, logiciels sur mesure |
| **Contact** | Formulaire de demande de maquette gratuite |

## Identité visuelle

Univers spatial inspiré de Sirius — fond sombre, étoiles animées, orbites, lueurs indigo/violet. Style Apple × Linear × studio tech premium.
